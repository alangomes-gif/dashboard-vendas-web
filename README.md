# Dashboard Web de Vendas & Indicadores (Front-end)

Interface web responsiva construída para exibição de métricas comerciais, indicadores de desempenho (KPIs) e histórico de transações em tempo real.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização moderna com Flexbox e Grid)
- **JavaScript (ES6+)** (Manipulação dinâmica do DOM)

## 📌 Funcionalidades
- **Cards de KPIs:** Métricas de faturamento, volume de pedidos e ticket médio.
- **Tabela Dinâmica:** Renderização dinâmica das transações usando JavaScript.
- **Design Responsivo:** Adaptação automatizada para dispositivos móveis e desktop.

## 🚀 Como Executar
1. Clone este repositório:
   ```bash
   git clone https://github.com/alangomes-gif/dashboard-vendas-web.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web.
